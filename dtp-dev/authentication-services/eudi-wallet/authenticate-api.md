# Authenticate API

All API calls are authenticated as described in [API Authentication](../../general-information/api-authentication.md). The APIs to issue and revoke the login VC are described in [Login VC API](../../verifiable-credential-services/login-vc/login-vc-api.md) and [Revoke login VC](../../verifiable-credential-services/login-vc/revoke-login-vc.md).

## Create authentication request

`POST /{tenantId}/auth-requests`

Must be called for each login attempt. Every call creates a new authentication request with a unique, single-use link. Which credential is requested (login VC, or PID as fallback) is defined in the authentication profile.

### Request

```json
{
  "userId": "CUST-000123",
  "state": "af0ifjsldkj",
  "nonce": "n-0S6_WzA2Mj",
  "redirectUri": "https://app.example.com/login/callback",
  "language": "de"
}
```

<table data-full-width="true"><thead><tr><th width="180">Field</th><th width="120">Required</th><th>Description</th></tr></thead><tbody><tr><td><code>userId</code></td><td>no</td><td>Unique identifier of the user in the external application. If submitted it must match the <code>userId</code> in the presented login VC. Returned as <code>sub</code> in the ID token. </td></tr><tr><td><code>state</code></td><td>yes</td><td>Opaque value generated by the external application. Returned unchanged on the redirect (CSRF protection).</td></tr><tr><td><code>nonce</code></td><td>recommended</td><td>Opaque value returned in the ID token to prevent replay attacks.</td></tr><tr><td><code>redirectUri</code></td><td>no</td><td>Redirect target after authentication. Must match an allowed redirect URI of the profile. If omitted, the static success / failed redirect URLs of the profile are used.</td></tr><tr><td><code>language</code></td><td>no</td><td>Language of the DTP pages (<code>de</code>, <code>fr</code>, <code>it</code>, <code>en</code>). Default from the profile.</td></tr></tbody></table>

### Response `201 Created`

```json
{
  "authRequestId": "7f3c2a9e-5b1d-4c8e-9a6f-2d4b8e1c0f57",
  "authUrl": "https://{dtp-host}/{tenantId}/auth/7f3c2a9e-5b1d-4c8e-9a6f-2d4b8e1c0f57",
  "status": "SCHEDULED",
  "expiresAt": "2026-10-20T12:30:00Z"
}
```

The `authUrl` is valid for 10 minutes and can be used only once. The external application redirects the end user to the `authUrl` or embeds it in an iFrame.

## Get authentication request

`GET /{tenantId}/auth-requests/{authRequestId}`

Returns the current `status`, `statusReason` and `statusDetails` of an authentication request, and which credential was presented. Can be used e.g. for polling in the cross-device flow or for support cases.

```json
{
  "authRequestId": "7f3c2a9e-5b1d-4c8e-9a6f-2d4b8e1c0f57",
  "customerId": "CUST-000123",
  "status": "AUTHENTICATION_SUCCESSFUL",
  "statusReason": null,
  "statusDetails": null,
  "credentialType": "LOGIN_VC",
  "vcId": "b1e3a9f2-0c4d-4f61-8a2e-9d7c5e3f1a08",
  "createdAt": "2026-10-20T12:20:00Z",
  "updatedAt": "2026-10-20T12:21:12Z"
}
```

<table data-full-width="true"><thead><tr><th width="180">Field</th><th>Description</th></tr></thead><tbody><tr><td><code>credentialType</code></td><td><code>LOGIN_VC</code> or <code>PID</code> (PID login as fallback). <code>null</code> as long as no credential was presented.</td></tr><tr><td><code>vcId</code></td><td>ID of the presented login VC. Only for <code>LOGIN_VC</code>.</td></tr></tbody></table>
