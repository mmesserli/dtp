# EUDI Wallet status reason and details

Additional details according status changing are returned in the webhook notification of identification as well as in the API that retrieve case detail data. The following 2 fields are returned:

* `ubiIdStatusReason`
* `ubiIdStatusDetails`

<table data-full-width="true"><thead><tr><th>ubiIdStatus</th><th>ubiIdStatusReason</th><th>ubiIdStatusDetails</th></tr></thead><tbody><tr><td><code>IDENTIFICATION_SUCCESSFUL</code></td><td><code>SUCCESS</code></td><td>-</td></tr><tr><td><code>IDENTIFICATION_FAILED</code> or <code>INITIALIZED</code> after <code>IDENTIFICATION_FAILED</code> (reason and details for last occurred error is shown)</td><td><code>ABORTED</code></td><td>User related reasons, see <code>Reason details</code> table below</td></tr><tr><td><code>IDENTIFICATION_FAILED</code> or <code>INITIALIZED</code> after <code>IDENTIFICATION_FAILED</code> (reason and details for last occurred error is shown)</td><td><code>CANCELED</code></td><td>Validation of the presentation failed, see <code>Reason details</code> table below</td></tr><tr><td><code>IDENTIFICATION_FAILED</code> or <code>INITIALIZED</code> after <code>IDENTIFICATION_FAILED</code> (reason and details for last occurred error is shown)</td><td><code>SIGNING_ABORTED</code></td><td><code>RESET_PASSWORD</code></td></tr></tbody></table>
