# API Authentication

To call the REST APIs of the identification and the signing service, the request must be authenticated by an API token (JWT) with a long life span (1 year). Requests sent to REST API **must** include the token in the header `Authorization: Bearer`.

NOTE: For details, please refer to the OpenAPI specification.
